# Онлайн-запись для мастера маникюра

Одностраничный сайт записи с отправкой заявок в Telegram-бот.
Без фреймворков и без npm-зависимостей: HTML + CSS + JS (ES-модули) + одна serverless-функция.

## Структура

```
├── public/                  ← всё, что видит браузер
│   ├── config.js            ← ⭐ ВСЕ НАСТРОЙКИ: фото, название, услуги, цены, время, контакты
│   ├── index.html           ← разметка страницы
│   ├── css/styles.css       ← стили (цвета — в :root в начале файла)
│   ├── js/app.js            ← логика формы, валидация, отправка
│   ├── js/calendar.js       ← календарь выбора даты
│   ├── js/dropdown.js       ← выпадающий список услуг
│   ├── js/i18n.js           ← переводы интерфейса (RU / UA / EN)
│   ├── js/phone.js          ← маска телефона +380
│   └── images/              ← сюда кладите свои фото
├── api/booking.js           ← serverless-функция Vercel: POST /api/booking
├── lib/booking.js           ← серверная проверка заявки + отправка в Telegram
├── server.js                ← локальный сервер (для запуска на компьютере)
├── .env.example             ← шаблон переменных окружения
├── vercel.json              ← заголовки безопасности для Vercel
└── package.json
```

## 1. Установка зависимостей

Нужен только **Node.js 18+** (https://nodejs.org). Внешних пакетов нет, `npm install` не требуется.

## 2. Локальный запуск

```bash
cp .env.example .env     # Windows: copy .env.example .env
# заполните TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID в .env
npm start
```

Откройте http://localhost:3000. (`npm run dev` — то же, но с перезапуском при изменении файлов.)

> Открывать `index.html` двойным кликом нельзя — ES-модули и API работают только через сервер.

## 3. Замена фотографии

`public/config.js` → `HERO_IMAGE`.
Положите фото в `public/images/` и укажите путь: `export const HERO_IMAGE = "images/hero.jpg";`
Рекомендуется вертикально-нейтральное фото ~2000px по ширине, до 500 КБ (jpg/webp). Важная часть кадра — по центру.

## 4. Услуги и цены

`public/config.js` → `SERVICES`. Добавьте/удалите строку вида:
```js
{ id: "french", name: "Французский маникюр", price: 900, duration: "1 ч 45 мин" },
```
Цена в заявке всегда берётся сервером из этого файла — подделать её из браузера нельзя.

## Языки (RU / UA / EN)

- Тексты про салон, услуги, адрес, преимущества — в `public/config.js`, в формате
  `{ ru: "…", uk: "…", en: "…" }`. Если язык не указан, показывается русский вариант.
- Тексты интерфейса (кнопки, подписи, ошибки) — в `public/js/i18n.js`.
- Язык выбирается автоматически по языку браузера, запоминается после переключения;
  ссылка на конкретный язык: `https://ваш-сайт/?lang=uk` (или `ru`, `en`).
- Язык по умолчанию и список языков — `LANGUAGES` в `config.js`.
- Заявка в Telegram всегда приходит на русском (`TELEGRAM.lang`) с пометкой, на каком языке был сайт у клиента.

## 5. Даты и время

`public/config.js` → `SCHEDULE`:
- `timeSlots` — слоты по умолчанию;
- `timeSlotsByWeekday` — особые слоты для дня недели (0 = Вс, 6 = Сб);
- `workingDays` — рабочие дни;
- `daysOff` — выходные/отпуск (`"ГГГГ-ММ-ДД"`);
- `daysAhead` — на сколько дней вперёд открыта запись;
- `minLeadMinutes` — за сколько минут до начала слот закрывается сегодня.

## 6. Подключение Telegram-бота

**Быстрый способ:** создайте бота в @BotFather, впишите токен в `.env`
(`TELEGRAM_BOT_TOKEN=...`), напишите боту любое сообщение и выполните:

```bash
npm run telegram:setup
```

Команда проверит токен, сама найдёт chat id, запишет его в `.env` и пришлёт тестовое сообщение.
Если `.env` ещё нет — она его создаст.

**Вручную:**

1. В Telegram откройте **@BotFather** → `/newbot` → задайте имя → получите **токен**.
2. Напишите своему боту любое сообщение (иначе бот не сможет вам писать).
3. Узнайте свой **chat id**: откройте в браузере
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":123456789`.
   Для группы: добавьте бота в группу, напишите в ней сообщение, повторите запрос — id группы начинается с `-`.
4. Впишите значения в `.env` (локально) или в Environment Variables на хостинге.

## 7. Переменные окружения

| Переменная | Обязательна | Описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | да | токен от @BotFather |
| `TELEGRAM_CHAT_ID` | да | куда присылать заявки |
| `ALLOWED_ORIGIN` | нет | принимать заявки только с этого домена, напр. `https://anna-nails.vercel.app` |
| `PORT` | нет | порт локального сервера (по умолчанию 3000) |

## 8. Деплой (Vercel, бесплатно)

1. Загрузите проект в GitHub (файл `.env` в репозиторий не попадёт — он в `.gitignore`).
2. https://vercel.com → **Add New → Project** → выберите репозиторий.
   Framework Preset: **Other**, Build Command — пусто, Output Directory — `public`.
3. **Settings → Environment Variables**: добавьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
4. **Deploy**. После изменения переменных нажмите **Redeploy**.

Альтернатива без GitHub: `npx vercel` в папке проекта, затем `npx vercel env add TELEGRAM_BOT_TOKEN` и т.д., `npx vercel --prod`.

Любой хостинг с Node.js (VPS, Render, Railway) тоже подойдёт: `npm start` + переменные окружения.

## 9. Проверка отправки

1. Запустите сайт, заполните форму и нажмите «Записаться» — в боте появится сообщение «🩷 НОВАЯ ЗАЯВКА».
2. Если пришла ошибка «Не удалось отправить заявку» — смотрите консоль сервера (локально) или **Vercel → Deployments → Functions/Logs**: там будет причина от Telegram (`chat not found` — неверный chat id или вы не написали боту; `Unauthorized` — неверный токен).
3. Проверка без формы:
   ```bash
   curl -X POST http://localhost:3000/api/booking -H "Content-Type: application/json" -d "{\"service\":\"manicure\",\"date\":\"2026-12-01\",\"time\":\"12:00\",\"hasAllergy\":false,\"name\":\"Анна\",\"phone\":\"+380671234567\",\"telegram\":\"\"}"
   ```
   (дата должна быть рабочим днём в пределах `daysAhead`).

## Безопасность

- Токен бота существует только в переменных окружения сервера; в браузер он не попадает никогда.
- `config.js` публичный — не храните в нём секреты.
- Сервер заново проверяет все поля, пересчитывает цену, проверяет дату и слот по расписанию.
- Сообщение отправляется в Telegram без HTML/Markdown-разметки — ввод клиента не может внедрить ссылки или форматирование.
- Защита от спама: скрытое поле-ловушка (honeypot) и лимит 5 заявок с IP за 10 минут.
- Двойная отправка заблокирована на клиенте (кнопка блокируется на время запроса).
